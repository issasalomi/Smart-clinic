# العيادة الذكية — نسخة تشغيلية أولية

## التشغيل

تحتاج Python 3.10 أو أحدث.

```bash
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

افتح http://127.0.0.1:8000

قاعدة البيانات SQLite فعلية وتُنشأ تلقائياً في `clinic.db`. جميع المدخلات محفوظة محلياً وتبقى بعد إعادة التشغيل. لحفظ نسخة احتياطية، أوقف البرنامج وانسخ `clinic.db` إلى مكان آمن.

## الوظائف المتاحة
- إضافة المراجعين وفتح ملفهم الموحد.
- تسجيل الزيارات والقياسات وحساب BMI في سجل المراجع.
- إدخال التحاليل يدوياً.
- إنشاء مسودات خطط غذائية، وتسجيل طريقة إنشائها (يدوي / تلقائي / مدمج).
- تسجيل منتجات المخزن وأشكالها (كبسولات، مسحوق، سائل).
- تسجيل فواتير كشفيات وفواتير منتجات منفصلة في التصنيف.
- لوحة تحكم وإحصاءات من قاعدة البيانات.

## حدود مهمة
هذه **نسخة تطوير محلية وليست نظاماً سريرياً جاهزاً للإنتاج**. لا تتضمن بعد: تسجيل الدخول والصلاحيات، تشفير الملفات، المراجعة والتوقيع السريري، تدقيق تغييرات السجلات، الذكاء الاصطناعي الفعلي، استخراج بيانات PDF/Word/Excel/الصور، مزامنة أجهزة متعددة، PostgreSQL، فواتير متعددة البنود أو ربط الصرف بخصم المخزون. لا تدخل بيانات مرضى حقيقية فيها. لا تعرض الخادم للإنترنت قبل بناء ضوابط الأمان والخصوصية.

## التوسع المقبل
ترحيل قاعدة البيانات إلى PostgreSQL، إضافة تسجيل دخول وصلاحيات وأثر تدقيقي، ربط ملفات الرفع، فحوص سلامة المكملات والأعشاب، إعداد مسودات AI موثقة وقابلة للمراجعة، فواتير أصناف وحركات مخزون ذرية، ثم النشر السحابي الآمن.
